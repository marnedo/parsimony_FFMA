This repository includes files such as R scripts, R Markdown instructions, and an example FASTA file for the hands-on computer lab on Introduction to Parsimony. This lab is part of the FFMA (Phylogeny and Phylogeography: Methods and Applications) course within the Master in Biodiversity at the Universitat de Barcelona. 
The example covers basic concepts of phylogenetic trees and tree manipulation in R, along with how to perform parsimony searches using different tree search strategies, various gap treatments, and methods for assessing node support through randomization approaches.
